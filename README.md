# React Password Generator

A simple and secure password generator built with React, TypeScript and Vite.

## Features

- Adjustable password length (4-64)
- Toggle character sets (lowercase, uppercase, numbers, symbols)
- Copy to clipboard
- Secure random generation using `crypto.getRandomValues`

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
